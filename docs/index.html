Pipeline

Code in this repo: tools/ (CLI) and addon/isaac_usd_importer (Blender extension).

Flatten & collectusd_flatten_collect.py resolves the USD stage and gathers textures.
Parse MDLmdl_parse.py reads Omniverse MDL parameters into a material spec.
Build node graphsmaterial_spec + base_materials map each template to Principled BSDF graphs.
Import & verifyblender_import.py, verify_export.py and render_check.py.
Add LiDARA sensor empty parented to the robot, a render layer with the LiDAR_Pass material override.

Honest labels. This is a Blender render of the Isaac warehouse with an animated LiDAR visualisation. It is not an Isaac Sim sensor run and produces no point cloud. 54 source textures lived on an Omniverse Nucleus server and were not localised; those materials fall back to constants.

NVIDIA warehouse assets and textures are not included in this repo and keep their own licence.
